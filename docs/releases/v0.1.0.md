首个可用版本：把 bead-me-up-scotty `v0.4.0`（commit `cf6dda1`）封装为 Windows 桌面应用，
界面与功能保持上游原样，本版本只增加桌面壳、打包与自动更新。

## 功能

- 双击启动，窗口内为完整 Scotty；无终端窗口
- 读取现有 `%USERPROFILE%\.config\bead-me-up-scotty\config.json`，项目列表原样可见
- 使用本机 `bd` 读写 beads；`bd` 不在 PATH 时进入 demo 模式并在日志中告警
- 单实例锁：重复启动只聚焦已有窗口，不新建服务
- 外部链接在系统浏览器打开，窗口只停留在 `127.0.0.1`
- 拒绝通知/摄像头/麦克风/定位权限，仅放行剪贴板读写（编号点击复制）
- 自动更新：启动 10 秒后检查、之后每 6 小时；下载完成提示重启或退出时安装
- 支持 `assets/skin.css` 视觉覆盖与 `patches/*.patch` 构建期补丁（本版为空）
- publish/showcase 随包可用（完整 Eleventy 依赖树）

## 环境与安装

- 环境：Windows 11 x64；`bd` 可选，不随包提供
- 资产：`scotty-desktop-Setup-0.1.0.exe`（123,746,087 字节）
- SHA-256：`9169a97eda4cb0ed15b3fec2a3aca7162aebc3ba04b18526e37e1af45588389b`
- 按用户安装，可选安装目录，不需要管理员权限
- 未签名：首次运行可能触发 SmartScreen，选择「更多信息 → 仍要运行」
- 卸载会移除安装目录；项目数据与配置不受影响

## 已知问题

- 仅 Windows x64；不捆绑 `bd`；不做代码签名
- 安装包约 123 MB，安装后约 414 MB
- 首次冷启动可能因杀软扫描而变慢
- 自动更新依赖 GitHub Releases；更新失败只写日志，不打扰使用
- publish 的 `deploy` 动作需要本机安装并登录 Vercel CLI
