# v0.1.0 验证记录

本文件是 v0.1.0 的内部交付记录，不进入 GitHub Release 正文。

## 自动化

- `npm run verify`：typecheck、lint、53 个单元测试、`build:server`、`GET /` 200 冒烟
- Playwright Electron：6 个用例
  - fixture 页面与标题
  - 外部链接不改变窗口
  - 第二实例直接退出
  - 剪贴板写入权限
  - skin.css 注入
  - 崩溃后弹窗、最多 3 次自动重启、进程清理
- `npm run e2e:real`：真实服务端冷启动 2.7–3.4 秒、3/3 项目可见、bd 缺失时告警启动、
  退出后无残留服务端进程

## 人工检查点

| 检查点 | 结论 |
|---|---|
| A：standalone 服务端 | 浏览器可见 Scotty，项目数据正常 |
| B：Electron 壳（fixture） | 窗口、标题、外链、退出正常 |
| C：真实 Scotty | 3 个项目可见；UI 改状态/优先级后 `bd show` 一致 |
| D：安装包 | 按用户安装（可选目录）、启动、读写、卸载清理均通过 |
| E：自动更新 | 0.1.0 检测/下载 0.1.1，弹窗一次，重启安装后版本变为 0.1.1 |
